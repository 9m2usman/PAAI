# PAAI — Personal Autonomous Agent Infrastructure

A reusable, multi-user autonomous AI agent infrastructure designed to execute tasks, use tools, maintain personalized memory, coordinate specialized agents, and perform real-world workflows with controlled permissions and human approval.

## Project Roadmap

- Phase 1: Understanding AI Agents
- Phase 2: Building the First Autonomous Agent
- Phase 3: Memory and Personalization
- Phase 4: Multi-Agent Orchestration
- Phase 5: Real-World Workflow Execution
- Phase 6: Multi-User Agent Infrastructure
- Phase 7: Advanced Autonomy
- Phase 8: Production Engineering

## Technology

- Python
- Groq LLM API
- SQLite
- Playwright
- Gmail and Google Calendar integrations

## Project Structure

- `app/agents/` — Agent implementations
- `app/core/` — Core runtime and configuration
- `app/memory/` — Memory and personalization
- `app/orchestration/` — Multi-agent orchestration
- `app/integrations/` — External integrations
- `app/security/` — Credentials and permissions
- `app/approvals/` — Risk and approval management
- `app/execution/` — Controlled action execution
- `app/workflows/` — Workflow management
- `app/documents/` — Document processing
- `tests/` — Automated tests

## Security

Never commit `.env`, API keys, OAuth secrets, access tokens, or other credentials.
